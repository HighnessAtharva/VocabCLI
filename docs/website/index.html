Everything you need to master vocabulary

📚

Dictionary & Thesaurus

Definitions, phonetics, audio pronunciation, commonly confused words, synonyms, and antonyms — all offline-first with smart caching.

🤖

AI Explanations

Go beyond the dictionary. Get etymology, register, when to use vs. avoid, and a memory tip — all streamed live to your terminal.

🧠

Spaced Repetition (SM-2)

The Anki algorithm built right in. vocab review shows only words due today. Rate your recall and intervals are auto-adjusted.

🎫

Flashcard Generator

Generate beautiful image flashcards for your learning, mastered, and favorite word lists with custom fonts and icons.

📖

AI Story Mode

VocabCLI writes a short story using all the words in your learning list. Reading in context dramatically improves retention.

💬

Interactive AI Tutor

Ask anything: "What's the difference between ephemeral and transient?" Get a streaming answer from a vocabulary expert AI.

📊

Graphs & Analytics

8 visualisations: word distribution by week/month, top tags, learning vs. mastered breakdown, and more.

🔥

Streaks & Gamification

Daily lookup streak tracking. See your longest streak and build the habit of learning a few new words every day.

🦙

Runs Locally with Ollama

All AI features work with local LLMs (Llama 3, Mistral, Phi-3) via Ollama. No API key, no cloud, complete privacy.

AI Features Spotlight

Before: Static Dictionary

$ vocab define ephemeral

EPHEMERAL
/ɪˈfemərəl/
──────────────────────────
adjective
1. Lasting for a very short time.

After: AI Deep-Dive

$ vocab ai explain ephemeral

✨ AI Explanation — EPHEMERAL
──────────────────────────
**Etymology**: From Greek *ephēmeros*
(*epi-* "on" + *hēmera* "day") — literally
"lasting only a day"…

**Register**: Literary / formal ✓
**Use when**: describing fleeting beauty,
transient trends, short-lived phenomena

🧠 **Remember**: Think of an EP record —
EPHEMERAL lasts about as long as one side.

Quick Install

# Core — always lightweight
$ pip install vocabcli
 
# + AI features (OpenAI / Ollama)
$ pip install "vocabcli[ai]"
 
# + NLP / spaCy / transformers (large, opt-in)
$ pip install "vocabcli[nlp]"

Requires Python 3.11+. See what's new in 2.0
